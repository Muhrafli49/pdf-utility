# PDF Utility

A simple PHP-based web application for processing PDF files locally.

### Features

* **Merge PDF** — Menggabungkan beberapa file PDF menjadi satu file.
* **Convert PDF to Word** — Mengubah file PDF menjadi dokumen Word yang dapat diedit.
* **Compress PDF** — Mengurangi ukuran file PDF dengan beberapa pilihan tingkat kompresi.

### Tech Stack

PHP, Bootstrap, Composer, FPDI, PHPWord, Smalot PDF Parser, dan Ghostscript.

### Usage

Dibuat untuk penggunaan lokal menggunakan XAMPP dan Apache, tanpa database.
